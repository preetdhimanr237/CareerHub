# CareerHub

A Django-based Job & Internship Portal.

## Features

- Student Registration & Login
- Company Registration & Login
- Job Posting
- Job Search & Filter
- Job Applications
- Application Status
- Student & Company Profiles
- Admin Management

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Future Improvements

- Student Dashboard
- Company Dashboard
- Custom Admin Dashboard
- Job Pagination
- Deployment
